One image summing up the world's news of **Tuesday 17 November 2026**:
the Kerch Bridge road arch collapsing after a second straight day of
Ukrainian strikes, an Iranian drone fired at a US radar base in Bahrain,
Japanese jets scrambled over suspected Russian planes, UK sanctions on
West Bank settlement builders, the Pentagon's ninth failed audit, and
the worst US measles year since 1991 — plus the Geneva talks on banning
lethal autonomous weapons. All stories were reported on 17 November 2026;
sources are named on the image (Reuters, Al Jazeera, AP, CNN, CDC).

## Run

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

The program copies `entry.png` (1024×1024, rendered from `render.html`
with original vector icons — no photographs) to `$MAKEFUN_OUTPUT_DIR/entry.png`
and verifies the copy byte for byte. It runs offline with the Node
standard library only, and both runs write identical bytes.
